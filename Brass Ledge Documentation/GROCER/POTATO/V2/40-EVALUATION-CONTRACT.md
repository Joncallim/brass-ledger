# V2 Evaluation Contract

Backlink: [[README]]

This separates machine-provable structure from human-only product evidence.

# 1. Machine-provable contract

The complete Kestrel implementation must prove:

- deterministic execution/replay + V1 isolation;
- ruleset/content/prototype-format boundaries;
- revision/stale-write protection;
- hidden-world/adversary isolation;
- explicit authorised history → source fact → evidence boundaries;
- exact reconciliation against the #100 architecture vectors in [[23B-HQ-BELIEF-STATE-SPACE-AUDIT]] / `23D-HQ-BELIEF-STATE-SPACE-VECTORS.json`;
- deterministic HQ evidence reduction and strict safe projection;
- diagnostic evidence has categorical meaning without numeric weighting/voting;
- lower-grade contrary evidence remains visible but does not automatically erase a diagnostic direction;
- intent assessment, tactical warning and public-case basis remain separate;
- all 10 algebraic assessment/warning states and 15 basis-pattern/warning presentation states are total;
- every credible public case has a specific claim direction, one diagnostic source and independent corroboration;
- claim direction is preserved without becoming physical preparedness/warning;
- assessment/warning/public-case evidence use role-specific currency;
- warning gain, refresh and stale loss are deterministic and explainable;
- stale evidence remains historical;
- superseded evidence never resurrects;
- routine C3 coverage is bounded rather than omniscient;
- world prose and R6 action/row never become analytic evidence;
- historical HQ belief cannot be rewritten by later state/truth;
- #100 semantic model is content-identity stable without persisted belief state;
- #102 collection producer semantics are separately identity-covered;
- explainable recommendation with standing-intent relevance;
- warning affects only explicitly warning-sensitive decisions;
- current public-case availability derives from #100 + irreversible source-use state rather than a persisted credibility mirror;
- commander-only actions never become delegated recommendations;
- all-Delegate package always legal;
- complete-package effects order-independent;
- Ravellan receives only closed observations and relied-upon policy paths are normally reachable;
- concrete consequences + costly recovery through C5;
- Lattice changes action/information space without becoming mandatory;
- Lattice has one default unused target in C4 and a different unused target in C5;
- no no-task or same-target fake choice;
- target/target-order differences are mechanical, not prose/evidence count only;
- consequential choices are elastic;
- no player-safe dominated trap;
- legitimate hidden-state-dependent risk is not falsely rejected;
- local dominance accounts for scarce intervention/action-space cost;
- public attribution’s exact claim and source cost are disclosed before use;
- terminal route legality uses current warning/physical adequacy independently from claim direction;
- final routes apply authoritative post-route effects before classification;
- every player-known terminal state has at least one response and no displayed dominated pair;
- no universal final answer;
- no forced hard loss before C6 without prior counterplay;
- no success snowball eliminating late trade-offs;
- no dead persisted observation/state/content retained for symmetry.

[[31-HEADLESS-DESIGN-LAB]] owns exact full-game diagnostics.

# 2. Global Pareto comparison

Whole-run policy comparison uses:

- Beacon security;
- partner consent/access;
- reserve readiness;
- commitment integrity.

Classification and severe flags remain separate. No weighted score.

Policy A dominates B only if A is no worse on every main dimension for every paired run, strictly better somewhere and never worse in any paired run.

# 3. Player-safe local package dominance

For one player-safe state:

1. group all compatible hidden realities;
2. compare complete legal packages differing at the focal choice;
3. preserve Delegate/Intervene/Task authority cost;
4. include remaining attention and options foreclosed/preserved;
5. simulate all compatible realities.

A is dominated only when comparator B is no worse across every compatible hidden reality and all authority/classification/severe dimensions, strictly better somewhere, and A has no compensating information/capability/recovery/action-space value.

A risky choice that wins in some compatible hidden states and loses in others is not dominated by hindsight.

# 5. Role-specific intelligence currency gate

Assessment, warning and public-case relevance are separate.

Require:

- focused buildup assessment/public C4–C6 but warning C4–C5;
- focused empty assessment C4–C5 but public C4–C6;
- Lattice landing warning current from C5/C6 result through C6;
- warning can be gained, refreshed and lost-stale while assessment remains unchanged;
- stale evidence remains historical;
- replacement is permanent and older evidence never resurrects;
- C5/C6 explicitly communicates warning usable or absent.

A single universal `activeThroughCycle` is a blocker.

# 6. Public-case and source-use gate

Credible public case requires:

- current source-sensitive diagnostic in direction D;
- current same-direction source-sensitive corroborator from another `corroborationGroupId`;
- no opposite-direction occurrence current for assessment or public-case use.

Require:

- one diagnostic source → tentative;
- two indicators → tentative;
- eligible both ways → tentative/null;
- directionless credible impossible;
- exactly two deterministic support occurrences/groups for credible;
- source labels and corroboration groups are not conflated;
- directional internal estimate may survive a weak contrary item while public case remains tentative;
- current availability derives from #100 + unspent source;
- source Use persists exact direction/support fingerprint and never regenerates/relabels.

# 7. Claim direction versus route capability

Claim direction records what can be exposed, not military capability.

Require paired terminal fixtures proving direction alone does not change:

- Beacon preparation/exposure;
- current warning;
- reserve;
- partner authority;
- physical hold feasibility.

If a direction-specific Hold route is pruned, complete player-safe dominance must justify it. If preparation/coercion claims are mechanically identical in all co-eligible states except copy/history, #107 flags the distinction as underpriced rather than inventing arbitrary differences.

# 9. Lattice task and target-order gate

When Lattice is operational:

- HQ selects one unused target in C4 and a different unused target in C5 from standing priority;
- player may retarget at zero normal intervention;
- no zero-cost no-task;
- no same-target retask;
- focused staging never consumes the stronger landing target;
- all six ordered two-target schedules are tested where fully legal.

Canonical target IDs:

- `landing-force-staging`;
- `auxiliary-tasking`;
- `operational-sequence`.

The old `political-operational-sync` ID is invalid.

For identical C4 player-safe states, branch target orders and compare:

- assessment/warning/public-case trajectory;
- C5 recommendation/package effect;
- C6 route set;
- terminal Pareto/classification/severe state.

Flag globally dominated target/order, target whose difference is only prose/count, or standing-priority default universally inferior to another available order.

# 12. Human-only contract

Machines cannot establish:

- felt ownership;
- causal comprehension under real reading;
- spontaneous forward strategy;
- tension/regret/vindication/surprise/payoff;
- voluntary continuation/replay desire;
- whether two interventions/six cycles/prose density feel right;
- whether Intelligence feels useful rather than opaque/omniscient;
- whether estimate versus current warning is understood;
- whether evidence source/limitation context is enough without dossier overload;
- whether public claim meaning is clear;
- whether the mandatory two-target Lattice choice feels strategic rather than automatic;
- whether authority/source/tempo trade-offs are legible without coaching.

Fresh-player evidence only.

# 14. Formal human gate

After browser E2E + approved harness, use 8 fresh players with fixed thresholds:

- >=6/8 voluntarily want another turn/run;
- >=6/8 identify significant personal cause;
- >=6/8 state unprompted forward strategy;
- >=5/8 report meaningful regret/vindication/tension/surprise/payoff;

Repeated severe qualitative failure overrides counts.
