# V2 Evaluation Contract

Backlink: [[README]]

This separates machine-provable structure from human-only product evidence.

# Machine-provable contract

The complete Kestrel implementation must prove:

- deterministic execution/replay + V1 compatibility;
- ruleset/content/prototype-format boundaries;
- revision/stale-write protection;
- hidden-world/adversary isolation;
- explicit raw-history→source-fact observation boundaries;
- deterministic HQ evidence reduction / safe projection;
- diagnostic evidence has real categorical meaning without numeric weighting;
- weaker contrary indicators remain visible but do not automatically veto a diagnostic direction;
- intent assessment, tactical warning and public-case basis remain separate;
- every credible public case has a specific claim direction;
- claim direction is preserved without being treated as physical preparedness/warning;
- stale information leaves current judgement but remains historical/debrief-reconstructible;
- staleness/supersession-driven judgement changes are explainable;
- same-question retasking replaces older observation rather than stacking votes;
- source/method context is legible without a reliability meter;
- historical HQ belief cannot be rewritten by later truth;
- routine C3 coverage is bounded rather than omniscient;
- world prose cannot become analytic evidence;
- #100 semantics are content-identity stable without persisted belief state;
- explainable recommendation with standing-intent relevance;
- warning affects only explicitly warning-sensitive decisions;
- #101 one-shot directional attribution cannot be bypassed by #100 internal basis;
- commander-only actions never become free delegated recommendations;
- all-Delegate package always legal;
- complete-package effects order-independent;
- Ravellan receives only closed observations and relied-upon policy paths are normally reachable;
- concrete consequences + costly recovery through C5;
- Lattice changes action/information space without becoming mandatory;
- target/retask choices are differentiated by information consequence, not evidence count/prose;
- neither always-retask nor always-broaden is globally optimal where both should matter;
- consequential choices mechanically elastic;
- no player-safe dominated trap;
- legitimate hidden-state-dependent risk not falsely rejected;
- local dominance accounts for scarce intervention opportunity cost;
- public attribution/source exposure **and claim subject** are disclosed before use;
- terminal route legality uses warning and physical adequacy independently from attribution claim direction;
- a direction-specific Hold route is shown only where it is non-dominated in the complete player-safe state;
- final routes apply real post-route effects before classification;
- every player-known terminal state has at least one response and no displayed dominated pair;
- no universal final answer;
- no forced hard loss before C6 without earlier counterplay;
- no structural success snowball eliminating late trade-offs;
- no dead persisted observation/state retained for symmetry.

# Global Pareto comparison

Whole-run policy comparison uses:

- Beacon security;
- partner consent/access;
- reserve readiness;
- commitment integrity.

Never collapse to one score. Classification/severe flags remain separate.

Policy A globally dominates B only if A is no worse on every main axis for every paired run and strictly better somewhere with no paired run where B is better.

# Player-safe local package dominance

For one player-safe state:

1. group all compatible hidden realities;
2. compare complete legal packages differing at focal choice;
3. preserve delegated vs intervention authority cost;
4. include remaining/foreclosed same-cycle options;
5. simulate all compatible hidden realities.

A is dominated only when comparator is no worse on every relevant outcome/authority/severe dimension across every compatible hidden state, strictly better somewhere, and A has no compensating assessment/warning/public-case-direction/capability/recovery/action-space value.

# Intelligence reducer gate

`kestrel-binary-hypothesis-v2` must pass exhaustive categorical truth-table testing:

- prep diagnostic + coercion indicator → preparation weak;
- coercion diagnostic + prep indicator → coercion weak;
- diagnostics both directions → unclear conflicted;
- indicators both directions only → unclear conflicted;
- diagnostic only → directional coherent;
- one-side indicators only → directional weak;
- evidence count never overrules diagnosticity;
- material contrary indicator is surfaced whenever a diagnostic direction survives it.

A weak contrary report is therefore considered and disclosed without automatically erasing a stronger judgement.

# Assessment / warning gate

Require reachable:

- preparation assessment + warning none;
- usable warning + wider conflicted assessment;
- warning changes at least one later recommendation/route consequence;
- coherent preparation without warning does not receive warning-specific benefit.

# Public-case gate

Require:

- directional assessment with case none/tentative;
- usable warning with case tentative where authored;
- credible case only from one eligible diagnostic direction with no active opposite directional evidence;
- every credible case has exactly one direction;
- directionless credible impossible;
- internal directional judgement may survive a lower-grade contrary indicator while public case remains tentative;
- hidden truth with identical legitimate evidence leaves case state+direction equal;
- later `used` case never regenerates or changes direction.

# Claim direction vs route capability

Direction records **what can be truthfully exposed**, not physical capability.

Require paired terminal fixtures proving:

- preparation/coercion direction alone does not change Beacon preparation/exposure/warning/reserve/authority;
- if #27 makes Hold legal for both directions in the same physical/partner state, physical result is evaluated identically and safe claim/cause copy differs;
- any direction-specific pruning is justified by complete player-safe Pareto/classification/severe/source-cost dominance, not a hard “wrong claim” shortcut;
- if both directions are mechanically identical in every co-eligible state except copy/debrief, #107 flags the distinction as **underpriced** for product review rather than inventing arbitrary mechanics.

# Intelligence currency / history gate

Require:

- historical reroute/focused selectors use historical facts;
- later state never rewrites prior snapshots/source context;
- routine C3 report has no hidden-preparation input;
- world prose cannot change evidence;
- current query before current Ravellan fails closed;
- stale occurrence remains historical but leaves current reducer;
- staleness-driven change explicitly says earlier information is stale;
- supersession-driven change says newer observation replaced older one.

# Retask / same-question gate

When #102 exists:

- unresolved/non-conclusive target may be retasked;
- newer same-question occurrence replaces older one including same definition ID;
- repeat collection never stacks votes;
- rechecking consumes the cycle's Task Collection opportunity and therefore has breadth opportunity cost;
- at least one reachable state makes recheck sensible and another makes broadening sensible;
- neither always-retask nor always-broaden globally dominates where both are meant to matter;
- authored conclusive result removes redundant retask.

# Information / capability value gate

Information is useful only if it can change assessment, warning, public-case state/direction, attribution, recommendation/dissent, legal action/route or rational package choice.

Evidence count/richer prose is not value.

Require:

- at least one viable non-Lattice non-defeat history;
- at least one information-sensitive decision;
- no oracle-only survival requirement;
- at least two co-eligible target/retask choices with distinct downstream mechanics;
- no globally dominated target;
- safe basis identifies source/method context without numeric reliability score.

# Human-only contract

Machines cannot establish:

- felt ownership;
- causal comprehension;
- spontaneous forward strategy;
- tension/regret/vindication/surprise/payoff;
- voluntary continuation/replay desire;
- whether two interventions/six cycles/prose density feel right;
- whether Intelligence feels useful rather than opaque/omniscient;
- whether estimate vs warning distinction is understandable;
- whether source/method context is enough without dossier overload;
- whether players understand what a public case actually claims;
- whether rechecking vs broadening collection feels meaningful;
- whether two public-claim directions feel strategically meaningful enough;
- whether authority/source/tempo trade-offs are understandable without coaching.

Fresh-player evidence only.

# Formative smoke

After #104 + #107 and before browser tranche:

- 3 fresh players;
- complete replay-valid plain-text slice;
- uninterrupted/non-leading;
- no hidden truth/strategy coaching.

Stop/remediate if >=2/3 cannot explain major consequence, form next-command plan or voluntarily want to continue while another command remains.

Repeated severe patterns also stop the tranche, including:

- Intelligence arbitrary or omniscient;
- estimate vs warning misunderstood where it matters;
- public attribution option has no clear claim subject;
- judgement changes because reporting aged out but player cannot tell why;
- repeat collection feels like grinding an intel stat;
- retask/broaden choices feel fake;
- preparation/coercion public cases feel like cosmetic labels with no meaningful strategic consequence;
- information text too dense;
- paperwork/unknowable punishment/obvious trap/package incomprehension.

Smoke falsifies; cannot pass #110.

# Formal human gate

After browser E2E + approved harness, use 8 fresh players with fixed thresholds:

- >=6/8 voluntarily want another turn/run;
- >=6/8 identify significant personal cause;
- >=6/8 state unprompted forward strategy;
- >=5/8 report meaningful regret/vindication/tension/surprise/payoff;
- >=6/8 use ownership language.

Repeated severe qualitative failure overrides counts.

# Non-substitution

No AI/CI/lab/oracle/E2E/synthetic play passes #110. Failed human hypotheses route focused remediation, not threshold reinterpretation.
