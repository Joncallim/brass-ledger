# Browser E2E Contract

Backlink: [[README]]

This is the implementation authority for **#108 — proving the browser preserves the authoritative Kestrel game through the real web → server → sim → replay path**. It verifies mechanics/information integrity, never fun.

## Start gate

Do not begin #108 until #105/#106 are complete after the earlier `#104 → #107 → formative-smoke continuation` gate.

## Environment

Use the real built web app and production V2 API/DTO path with deterministic fixtures.

Test setup may seed known hidden state outside the player route, but production player endpoints must never gain a hidden/debug truth mode.

Assert semantic DTO/DOM state, not screenshots alone.

# Full-run golden path

At least one complete browser run must:

1. declare immutable standing direction;
2. leave at least one issue untouched at implicit Delegate;
3. use personal intervention;
4. create/test a real commitment/authority choice;
5. exercise Lattice or commander-only liaison;
6. reach the C5 collision;
7. choose one legal C6 course from the **pruned player-safe route set**;
8. show post-route terminal state/classification;
9. show `What HQ believed` then terminal truth debrief;
10. export/read a session that passes trusted replay.

Golden route is coverage, not intended strategy.

# Command-package authority

Prove:

- untouched issues submit `delegate`, not delegated final order IDs;
- server/sim derives delegated orders;
- all-Delegate package is legal, including representative C5 states;
- invalid cross-issue draft is safely explained/prevented;
- browser never silently changes another issue to repair it;
- server independently rejects incompatible package if client prevention bypassed.

# Intervention economy

Prove:

- first/second intervention budget updates;
- third normal intervention cannot submit;
- undo returns token;
- no prior intervention silently replaced;
- partner liaison always costs one normal intervention and never delegates;
- Task Collection costs zero normal interventions.

# Stale revision

Create a real stale draft and prove:

- server rejection;
- no silent retry/commit;
- authoritative projection refresh;
- changed issue/recommendation/reason visible;
- only safely remappable draft choices survive.

# Hidden-truth / DTO attack

Paired sessions with different hidden truth but same legitimate HQ/public inputs must produce deep-equal normal player semantics.

Assert normal JSON excludes:

- hidden posture/preparation;
- raw Ravellan action/policy row;
- raw `AdversaryObservation`;
- private ledger/state/hash;
- collection selector inputs;
- oracle/counterfactual state;
- probability/future branches.

Cycle 6 receives only:

- `seizure-underway`;
- `threshold-confrontation`;
- `pressure-receding`.

# Coalition → Ravellan signal timing/composition

Exercise [[37A-COALITION-TO-RAVELLAN-SIGNAL-MATRIX]]. Prove:

- Cycle-N action never causes same-cycle Ravellan reaction;
- C1 weak/credible watch signals;
- C2 quiet/visible/public signals + coordinated surge;
- C3 reassurance coherent signal;
- C4 targeted quiet prep discovery;
- C5 visible reinforcement / attribution discovery coalescing;
- C5 package never emits contradictory same-ID coverage values;
- C5 reserve use emits **no dead reserve-exhaustion observation**;
- raw signals absent from browser JSON.

# Intelligence / reroute / Lattice / liaison

## Reroute

`reroute-and-monitor` must show known civilian/political disruption, preserve reserve, and later deliver its indicator-only C3 auxiliary clue through ordinary HQ evidence. No generic +intel/hidden selector data.

## Lattice

Prove exact scheduled maturity, C4 target choice, next-update evidence, posture-only result isolation, no confidence/hidden-result branch in DTO, no normal token cost and target differentiation in targeted integration fixtures.

## Liaison

Prove one intervention consumed, indicator-only evidence, real obligation, no Delegate and no hidden-posture shortcut.

# C2 political/operational composition

Through normal APIs prove:

- active C1 channel + joint warning + visible surge → coordinated, no partner penalty;
- same surge without channel → partner worsens;
- public accusation worsens partner without promise and additionally breaches active promise;
- only authorised Ravellan signals emitted.

# C5 package / tempo / authority

Prove:

- `partner-authority` deterministic;
- active rapid formal channel + honour can authorise immediate sensitive action;
- without rapid channel, honour remains legal/C6-joint but cannot accompany immediate visible reinforcement/public attribution;
- act-then-inform buys unilateral same-cycle tempo at package-level breach/damage;
- concession buys immediate coordinated authority at severe cost;
- withdrawn + honour legal without restoring access;
- reserve/exposure effects invariant to issue order;
- no double political penalty.

# One-shot attribution / source cost

When credible:

- UI discloses before selection that public use spends the one-shot opportunity and exposes/compromises source;
- Hold preserves `credible` for possible C6 Hold And Expose;
- C5 use → `used`, source severe cost, immediate effects, no regeneration, C6 Hold removed;
- no hidden future outcome preview.

# Consequence reveal safety

Exercise delegated/personal callbacks, promises/authority, reroute clue, Lattice maturity and net C5 package effects.

Reveal must show observed change, belief-safe cause, history callback, unresolved pressure and future influence point without hidden truth/oracle/right-answer language.

# Cycle-6 route pruning / outcomes

Use deterministic terminal fixtures through normal authoritative APIs and match [[27-KESTREL-TERMINAL-MATRIX]] exactly.

## `pressure-receding`

- Quiet always;
- Hold And Expose only under its unspent-evidence/damaged-partner predicate;
- no Joint;
- no Emergency.

## `threshold-confrontation`

- Quiet always;
- Hold where 27 predicates hold;
- Joint only where it supplies player-known value over Quiet;
- no Emergency.

## `seizure-underway`

Prove route set is derived from the known adequacy/pruning predicates, not a fixed menu:

- no displayed Quiet route is known unable to hold Beacon;
- late-reaction Quiet is absent when legal Joint would strictly dominate it;
- no displayed Joint route is known unable to hold Beacon;
- clean Quiet + cooperative partner prunes inferior Joint/Hold as specified;
- Emergency is absent whenever legal Quiet or legal Joint already provides the known denial;
- Emergency is absent when it cannot hold and legal Hold And Expose can;
- Emergency remains as last-ditch fallback when no better viable route exists, including a known-doomed best-effort state after accumulated failure;
- Hold And Expose requires unspent credible attribution + partner access + seizure physical predicates and source cost.

Across fixtures exercise every final course family in at least one state where it is legal/useful and all four outcomes:

- Strategic Success;
- Costly Success;
- Political Defeat;
- Operational Defeat.

Final routes mutate post-route authoritative state:

- late Quiet reserve/severe cost;
- Joint reserve/partner effect;
- Emergency reserve/emergency-surge/possible partner cost;
- Hold attribution/partner/source cost.

No pruned route appears as phantom UI alternative.

# Terminal truth gating

Before completion: no prior hidden posture/preparation/policy history.

After replay-valid terminal completion: only explicit debrief-safe truth fields, never raw private state.

# Replay / export

Golden and representative hostile runs pass trusted replay with exact player/system ordering, state hashes/revisions, content identity and post-route state. Browser-local/tampered state never becomes authority.

# Accessibility / V1

Retain focused V1 E2E under V1 semantics; V1 need not adopt V2 UX.
