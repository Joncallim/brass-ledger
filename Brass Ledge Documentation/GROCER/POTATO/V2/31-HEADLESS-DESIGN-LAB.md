# Headless Design Laboratory

Backlink: [[README]]

This is the implementation authority for #107. It falsifies broken structure before browser/human time is spent. It cannot certify fun.

[[27-KESTREL-TERMINAL-MATRIX]], [[37A-COALITION-TO-RAVELLAN-SIGNAL-MATRIX]] and [[39-KESTREL-CROSS-SYSTEM-COMPOSITION]] supply final composed invariants.

## Machine / human boundary

The lab may determine seed fairness, policy/local-course dominance, fake choices, information/capability/recovery value, adversary reachability/isolation, complete-package consistency, terminal route completeness, dead state and structural snowball.

It may not determine ownership, tension, regret, real-reading comprehension or voluntary replay desire.

# Deterministic policy cohort

- `delegate-all` — accept authoritative staff recommendation everywhere.
- `intervene-all-where-legal` — attempt maximum intervention use through fixed authored preference among non-recommended alternatives, always as complete legal package.
- `recovery-first` — prefer authored recovery.
- `deterrence-first` — prefer visible/physical denial and forward readiness.
- `intelligence-first` — understanding-oriented intent, scheduled Lattice, legitimate information courses.
- `coalition-first` — partner-oriented intent, consultation/authority/commitment preservation.
- `random-valid` — enumerate **complete legal command sets** and choose deterministically/uniformly; never sample issue choices then repair.

Generic policies exercise the 81 standing-intent combinations where specified/practical; fixed-strategy probes report fixed intent honestly.

# Oracle frontier

Test-only hidden-truth explorer enumerates feasible legal continuations/non-dominated frontier. It never defines a canonical best move, staff advice or scalar optimum and never enters live gameplay.

# Outcome relation

Primary Pareto axes:

- Beacon security;
- partner consent/access;
- reserve readiness;
- commitment integrity.

Retain terminal classification + explicit severe flags separately. No weighted score.

For **within-cycle local comparisons**, also preserve the player-authority cost of reaching the branch:

- number of normal interventions consumed;
- remaining normal intervention budget;
- resulting set of other same-cycle legal packages/options still reachable.

This is action-space opportunity cost, not a fifth success score.

# Diagnostics

## 1. Seed viability / oracle fairness

Require no forced hard loss before C6 without earlier counterplay, distinct strategies reaching C6, multiple non-dominated profiles, real recovery through C5 and no oracle proof that unavailable hidden truth is required to escape otherwise unavoidable defeat.

## 2. Policy dominance

Across identical viable comparison sets, A dominates B only when A is no worse on all Pareto axes, no worse in classification/severe state where applicable and strictly better somewhere. Never fix dominance with randomisation/rubber-banding.

## 3. Decision Elasticity

From identical verified pre-state, branch every authored consequential alternative. Elastic differences may appear in persistent state, belief, agenda/advice, legal action/capability/final-route space, Ravellan path or terminal result. Prose-only divergence is fake.

## 4. Player-safe local course/package dominance

A local decision cannot be evaluated as an isolated order effect when selecting the order may consume one of only two personal interventions.

For one player-safe pre-state:

1. group every hidden history compatible with the same legitimate player information;
2. compare **complete legal command packages** that differ at the focal decision while holding other choices equivalent where possible;
3. include the focal choice's current intervention cost and the resulting loss/retention of other same-cycle legal interventions in the comparison;
4. simulate every compatible hidden reality through normal authoritative transitions.

Compare:

- terminal Pareto vector;
- terminal classification;
- explicit severe flags;
- current/remaining intervention budget and same-cycle action-space opportunity cost;
- later legal action/recovery/capability space;
- information value as specific evidence/action-space effect.

Flag A dominated by B only when B is no worse across **every** compatible hidden reality **and no worse in intervention/action-space opportunity cost**, strictly better somewhere, and A has no compensating information/capability/recovery value.

Consequences:

- a beneficial political intervention does **not** automatically dominate the delegated silent/routine baseline merely because it directly improves partner state; it spends scarce personal attention unless standing direction already delegates it;
- when standing partner direction makes joint warning/reassurance the recommendation, the package comparison changes accordingly because the action no longer consumes an intervention;
- a legitimate risky course that wins in some compatible hidden realities and loses in others is not dominated.

Explicitly test:

- C2 quiet / visible / reroute shipping;
- C2 silence / joint warning / accusation under both partner-oriented and non-partner-oriented standing intent;
- C3 routine contact / reassurance under both recommendation baselines;
- C4 recover / quiet prepare / visible press;
- C5 quiet / visible / hold Beacon;
- C5 honour / unilateral / concession packages where comparable;
- C5 hold/use one-shot source-sensitive attribution;
- every displayed C6 route in same safe terminal state.

## 5. Intervention / delegation value

Report intervention opportunities/usage, downstream elasticity and real delegated cost. Flag always-spend-both or never-intervene dominance and mechanically empty overrides.

## 6. Strategy separation

Intelligence-, coalition-, deterrence- and recovery-first must diverge on some viable seeds across Lattice/liaison, partner/authority, Beacon state, reserve, evidence/attribution, Ravellan path and final outcomes.

## 7. Information value

Information matters only when it changes belief/advice/route/action-space or later rational decisions. It need not always improve outcome. Flag legitimate information that never matters while oracle truth is necessary.

## 8. Capability / target relevance

Lattice must change legal information/action space and create later elastic choice. Require viable non-Lattice non-defeat history. At least two targets from same reachable pre-state must create different downstream mechanics. Reroute/liaison remain narrower/cost-different alternatives.

## 9. Recovery reachability

From every reachable C1–C5 non-terminal state test promised reserve, partner, Beacon, missed-Lattice and information counterplay. Flag recovery that cannot change threatened state or is costless/dominant.

## 10. Terminal route completeness / dominance

For every abstract/reachable C6 player-known state:

1. derive route set from [[27-KESTREL-TERMINAL-MATRIX]];
2. assert non-empty;
3. execute every displayed route;
4. record post-route Pareto/classification/severe flags;
5. run Diagnostic 4 pairwise (terminal routes consume no normal C1–C5 intervention budget, so this reduces to outcome/action-space comparison).

Canonical terminal invariants:

- pressure receding: Quiet; Hold only where source-for-politics trade meaningful; no Joint/Emergency;
- threshold: Quiet; no Emergency; Joint only for known coalition value over Quiet; Hold under evidence/partner predicate;
- seizure: no known-futile Quiet/Joint; late Quiet pruned when Joint strictly dominates; Emergency pruned whenever legal Quiet/Joint provides known denial and when Emergency cannot hold but Hold can; Emergency remains last-ditch when no better route exists.

Canonical exhaustive abstract-state expectation:

- **zero empty route sets**;
- **zero displayed pairwise-dominated route pairs** under the player-safe Pareto + classification + severe-cost relation.

Also prove C5 attribution use removes Hold, source exposure is severe, Emergency is never clean Strategic Success, each final family is useful somewhere viable and no route universal.

## 11. Intent relevance

Vary one standing-intent answer at a time with other inputs fixed. Every answer must alter reachable recommendation/reason or delegated consequence somewhere. Require at least one real field conflict.

## 12. Adversary responsiveness / signal reachability / isolation

Using #99 + 37A prove observation responsiveness/private-state isolation, normal reachability of CF-1/T-1, GP-1 and C6 strong-denial chain, deterministic coalescing, no contradictory signals, visible/quiet C5 divergence, C2–C4-only reserve exhaustion and absent dead C5 exhaustion.

## 13. Composed-command integrity

Prove all-Delegate legality, complete policy packages, liaison cost/authority, C2 coordination, C5 channel/tempo, withdrawn+honour, issue-order invariance and Hold/Use attribution trade.

## 14. Snowball / trivial late game

Flag early-success branches that remove late trade-offs. Never add rubber-banding automatically.

## 15. Agenda collision

Report issue count, credible personal alternatives, intervention budget and elastic alternatives. C3/C5 must expose >2 credible personal-intervention candidates in promised histories; collision manufactured by fake/dominated choices fails.

## 16. Dead state / observation

Every persisted field/evidence/observation needs a downstream policy/state/legality/readout/debrief/replay-integrity purpose. C5 reserve-exhaustion remains absent as canonical regression.

# Counterfactual integrity

Clone verified state/revision, use normal sim, never mutate source, remain deterministic and diagnostic-only.

# Lab self-test fixtures

Must detect:

- delegate-all / intervene-all dominance;
- inelastic choice;
- player-safe dominated trap;
- **beneficial intervention that spends a scarce token and therefore must not be falsely treated as dominating a delegated baseline**;
- risky-but-non-dominated hidden-state choice (must not false-positive);
- missing recovery;
- mandatory Lattice / equivalent targets / worthless information;
- irrelevant intent / strategy sameness;
- adversary-private / collection-posture leak;
- doomed hidden seed;
- invalid all-Delegate package;
- issue-order dependence / contradictory signal / dead observation;
- empty terminal route set / displayed dominated terminal pair / universal route;
- severe-cost-blind dominance;
- trivial snowball.

Then run canonical Kestrel. Green structure only authorises formative smoke/UI spend, never #110.

## Rejection conditions

Reject #107 if it creates scalar fun/balance score, ignores intervention opportunity cost or severe/source cost, trains gameplay agent, treats oracle as live recommendation truth, repairs invalid sampled packages, preserves dead state for symmetry, feeds diagnostics into gameplay, changes Ravellan dynamically to pass metrics or claims machine evidence passes human gate.
