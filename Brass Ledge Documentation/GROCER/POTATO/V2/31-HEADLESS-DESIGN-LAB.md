# 1. Machine / human boundary

The lab may determine:

- exact implemented-state reachability;
- seed fairness/viability;
- policy/local-package dominance;
- fake/inelastic choices;
- intervention/delegation value;
- strategy/intent separation;
- assessment/warning/public-case orthogonality;
- source/corroboration/currency/supersession integrity;
- information/capability/target-order relevance;
- recovery reachability;
- adversary signal reachability/isolation;
- complete-package consistency;
- terminal-route completeness/non-dominance;
- dead state/observation;
- structural snowball/triviality.

It may not determine felt ownership, tension, regret, reading comprehension or voluntary replay desire.

# 2. Deterministic policy cohort

- `delegate-all`;
- `intervene-all-where-legal`;
- `recovery-first`;
- `deterrence-first`;
- `intelligence-first`;
- `coalition-first`;
- `random-valid` over complete legal packages.

Generic policies exercise the 81 standing-intent combinations where specified/practical. Fixed strategies report fixed intent honestly.

# 3. Oracle frontier

Test-only hidden-truth exploration may enumerate feasible continuations and non-dominated terminal frontiers.

It never defines a canonical best move, staff advice, or scalar optimum and never enters live gameplay.

# 4. Outcome relation

Primary Pareto axes:

- Beacon security;
- partner consent/access;
- reserve readiness;
- commitment integrity.

Retain terminal classification + explicit severe flags separately. No weighted score.

For local comparisons also retain normal interventions consumed, remaining attention and same-cycle options foreclosed/preserved.

# 5. Architecture-vector reconciliation

Before any balance diagnostic, reproduce the implemented legal-game graph and compare it with the #100 over-approximation.

Required:

- every implemented #100 reducer truth row matches 23D;
- every implemented evidence definition/mapping matches 23C;
- every implemented history is a member of the 23D architecture envelope;
- no legal full-game history creates a state outside 23D without an approved semantic amendment/digest change;
- legal package constraints may narrow counts, but the report explains every narrowed state/trajectory/definition;
- all producer definitions relied upon by gameplay remain reachable in at least one legal full-game history or are flagged dead.

Do not treat copied fixture values as generated proof. The #107 graph is independently produced from authoritative sim/content transitions.

# 6. Seed viability / oracle fairness

Require:

- no forced hard loss before C6 without earlier meaningful counterplay;
- materially different non-oracle strategies reach C6;
- multiple non-dominated terminal profiles across viable seeds;
- promised recovery remains reachable through C5;
- unavailable hidden truth is never required merely to survive.

# 7. Policy dominance

A policy dominates another only when it is no worse across Pareto/classification/severe dimensions for every paired run and strictly better somewhere.

Flag universal dominance by Delegate-all, Intervene-all or one standing strategy family.

Never fix through randomisation/rubber-banding.

# 8. Decision Elasticity

From identical verified pre-state, branch every authored consequential alternative.

Elastic differences may occur in:

- persistent campaign state;
- HQ evidence/assessment/warning/public case;
- agenda/recommendation/dissent;
- legal action/capability/final-route space;
- Ravellan observation/policy path;
- terminal Pareto/classification/severe state.

Prose-only divergence is fake.

# 9. Player-safe local package dominance

For one player-safe state:

1. group every compatible hidden reality;
2. compare complete legal packages differing at the focal choice;
3. preserve delegated/intervention/task authority cost;
4. include foreclosed same-cycle options;
5. simulate all compatible hidden realities through normal authoritative transitions.

A is dominated only when B is no worse in every compatible hidden reality and no worse in authority/severe dimensions, strictly better somewhere, and A has no compensating information/capability/recovery/action-space value.

Do not reject legitimate risky choices by oracle hindsight.

# 10. Exceptional commander authority

Exactly:

- C2 accusation;
- C4 liaison;
- C5 attribution use

require one normal intervention and can never be recommended/delegated.

Lattice retargeting remains zero normal intervention and is not a fourth commander-only course.

# 11. Political baselines

Prove C1 informal, C2 silence, C3 routine contact and C5 attribution Hold are staff baselines except where standing partner direction legitimately selects a positive non-exceptional course.

# 12. C5 package recommendation / protected boundary

Prove:

- untouched all-Delegate package legal;
- package-level partner-consultation boundary;
- rapid-channel Honour;
- Concession/Act applicability;
- withdrawn+Honour;
- final deterministic Political tie:
  - compatible Honour > Concession > Act;
  - no Honour + conditional/withdrawn → Concession > Act;
  - no Honour + cooperative/uneasy → Act > Concession.

Never array/random/seed tie-breaking.

# 13. Intervention / delegation value

Flag if always spending both or never intervening is weakly better in every comparable state, or if many overrides are mechanically empty.

# 14. Strategy separation

Intelligence-, coalition-, deterrence- and recovery-first must diverge across viable seeds through some of:

- Lattice maturation/target order or liaison;
- partner/authority/commitment;
- Beacon/reserve;
- assessment/warning/public-case timing;
- Ravellan observation/policy path;
- final route/outcome.

# 15. Assessment reducer integrity

Exhaustively test all 16 `Pdiag/Cdiag/Pind/Cind` rows for `kestrel-binary-hypothesis-v1`.

Required:

- preparation diagnostic + coercion indicator → preparation/weak;
- coercion diagnostic + preparation indicator → coercion/weak;
- diagnostics both directions → unclear/conflicted;
- indicators both directions only → unclear/conflicted;
- diagnostic only → directional/coherent;
- multiplicity cannot change direction;
- material contrary occurrence always shown when direction is qualified.

Deliberately buggy majority-vote and any-contrary-veto reducers must fail.

# 16. Assessment / warning orthogonality

## Algebraic totality

Prove all 10 legal assessment/warning pairs and all 15 basis-pattern/warning presentation mappings from 23B/23C.

In particular, `coercion / weak + usable warning` must render sensibly even though canonical producers currently do not reach it.

## Producer reachability

Reconcile exact Kestrel producers with 23D:

- 9 assessment/warning pairs reached;
- 11 basis-pattern/warning states reached;
- preparation assessment + no warning reachable;
- usable warning + wider conflicted assessment reachable;
- warning affects at least one later advice/route predicate;
- coherent preparation without warning receives no warning-specific benefit.

# 17. Role-specific currency and warning transitions

Prove assessment, warning and public case use separate currentness rules.

Critical paths:

- focused buildup remains assessment/public-current through C6 but warning-current only C4–C5;
- focused empty is assessment-current only C4–C5 but public-current through C6;
- C4 Lattice landing result refreshes warning through C6;
- stale/superseded evidence remains historical;
- supersession is permanent and older reports never resurrect.

Reproduce 23D warning transition counts across 4,112 producer schedules:

- gained 1,656;
- refreshed 552;
- lost-stale 552;
- lost-superseded 0;
- lost-mixed 0.

The product must explicitly communicate warning status at C5/C6. A missing visual component is not warning-none semantics.

# 18. Public-case orthogonality and traceability

Require:

- directional estimate with case none/tentative;
- usable warning with tentative case;
- credible only from eligible diagnostic + same-direction corroborator in another corroboration group + no current opposite direction;
- one source/two indicators/directionless case never credible;
- exact two-item deterministic support basis;
- source/corroboration groups not conflated;
- hidden truth with equal legitimate evidence leaves public case equal;
- used claim direction/support basis never regenerates or changes.

## Direction versus physical capability

Vary preparation/coercion case direction while holding safe physical/partner state equal.

Claim direction alone must not change preparedness, warning, reserve, exposure or physical hold feasibility. If a direction-specific Hold route is pruned, the report must show complete player-safe dominance, not a hard-coded “wrong claim” rule.

Flag if the two directions are mechanically indistinguishable in every co-eligible state; do not invent random bonuses automatically.

# 19. Historical and information-boundary integrity

Require:

- reroute C3 uses C2 facts;
- focused C4 uses C4 result-time facts;
- later state never rewrites an earlier snapshot/source/limitation;
- command Q/future entries cannot affect Q pre-command intelligence;
- routine C3 report never reads hidden preparation;
- C4 world prose never changes evidence;
- R6 action/row never enters evidence/warning;
- current query before current Ravellan decision fails;
- unverified import cannot project.

# 20. Lattice mandatory task flow and target-order relevance

When Lattice is operational:

- exactly one unused target executes in C4;
- one different unused target executes in C5;
- HQ default is determined by standing main priority;
- player retargeting costs zero normal intervention;
- no zero-cost no-task;
- no same-target retask;
- all six ordered target sequences are reachable unless complete-game applicability legitimately removes one and reports why.

Canonical target IDs:

- landing-force-staging;
- auxiliary-tasking;
- operational-sequence.

Focused collection never consumes landing target. Reproduce 138/138 focused-positive histories where later landing changes C5 assessment.

For every reachable C4 safe pre-task state, branch all six ordered two-target sequences where applicable. Report:

- assessment/warning/public-case trajectory;
- C5 recommendation/package effect;
- C6 route-set effect;
- terminal Pareto/classification/severe effect;
- target/order dominance or equivalence.

Flag:

- globally dominated target or ordered sequence;
- target whose difference is only prose/evidence count;
- standing-priority default that is universally inferior to another available order;
- mandatory Lattice that eliminates all viable non-Lattice strategies.

# 21. Information value

Information matters only when it changes one or more of:

- assessment;
- warning;
- public-case/source-use opportunity;
- recommendation/dissent;
- legal action/route;
- rational package choice.

Require:

- at least one viable non-Lattice non-defeat history;
- at least one history where better/different information changes a sensible legal decision;
- preparation/coalition strategies can succeed with imperfect intent picture at different costs;
- oracle truth is not required merely to avoid hidden unavoidable loss.

# 22. Recovery reachability

Every reachable C1–C5 deteriorating state retains promised costly counterplay. Flag a recovery that cannot change threatened downstream state or is free/dominant.

# 23. Terminal route completeness / dominance

For every player-known C6 state:

1. derive routes from [[27-KESTREL-TERMINAL-MATRIX]];
2. assert non-empty;
3. execute each;
4. record post-route Pareto/classification/severe state;
5. run player-safe local dominance.

Canonical invariants:

- pressure receding: Quiet; Hold only where meaningful; no Joint/Emergency;
- threshold: Quiet; no Emergency; Joint only for real known value; Hold under predicates;
- seizure: no known-futile Quiet/Joint; late Quiet pruned when Joint dominates; Emergency fallback-only;
- clean Quiet uses **current warning role**, not historical warning or preparation assessment;
- stale focused warning can remove clean-Quiet status while assessment/public case remains current;
- Hold uses current public case and physical/partner adequacy independently from claim direction;
- source use freezes exact two-item support basis.

Expect zero empty route sets and zero displayed pairwise-dominated route pairs. No final route universal.

# 24. Intent relevance

Every standing-intent answer changes some reachable recommendation/reason/delegated consequence, including Lattice default target order. Require at least one real conflict between intent fields.

# 25. Adversary responsiveness / signal reachability

Prove authorised observations change #99 where permitted, private-state isolation, normal reachability of relied-upon rows, deterministic coalescing, no contradictory/dead signals and no C5 reserve-exhaustion observation.

# 26. Composed-command integrity

Prove complete package construction, C2 coordination, C5 channel/tempo, withdrawn+Honour, issue-order invariance, exceptional authority and current directional source trade.

# 27. Snowball / trivial late game

Flag early-success histories that remove later trade-offs, make one information sequence universally superior or collapse route outcomes. Never add rubber-banding automatically.

# 28. Agenda collision

Report per-cycle issue count, credible personal alternatives, intervention budget and elastic options. C3/C5 must expose >2 credible personal-intervention candidates in promised histories; fake/dominated collision fails.

# 29. Dead state / observation

Every persisted field/evidence/observation needs downstream policy/state/legality/readout/debrief/replay purpose. C5 reserve-exhaustion and removed integrated-auxiliary definitions remain absent.

# 30. Counterfactual integrity

Branches clone verified state/revision, use authoritative sim, never mutate source and remain diagnostic-only.

# 31. Report

Produce deterministic machine-readable output + concise human summary covering:

- 23D reconciliation;
- policy/local dominance and Decision Elasticity;
- exceptional authority/package ties;
- strategy/intent separation;
- reducer algebra and producer reachability;
- warning currency/refresh/loss;

- historical/information boundary;
- Lattice target/order relevance;
- information value;
- recovery;
- terminal completeness/diversity;
- adversary fairness;
- dead-state/snowball/agenda collision.

No fun score.

# Rejection conditions

Reject #107 if it creates a scalar fun/balance score, ignores intervention/severe/source cost, collapses intelligence products, treats evidence count as value, uses one currency window, forgets stale history, permits fake no-task/retasking, treats claim direction as physical capability, trains a gameplay agent, uses oracle truth as live advice, repairs invalid packages, preserves dead state, allows exceptional authority through Delegate, leaves ties to array order, feeds diagnostics into gameplay, changes Ravellan dynamically to pass metrics or claims machine evidence passes the human gate.
