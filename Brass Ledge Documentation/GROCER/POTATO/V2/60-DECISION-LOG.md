# V2 Decision Log

Backlink: [[README]]

| ID | Decision | Why |
| --- | --- | --- |
| D1 | V2 is a separately versioned ruleset. | Protect V1 save/replay truth and permit a real interaction experiment. |
| D2 | Kestrel uses six command cycles and one bounded adversary. | Small enough for rapid testing; enough room for ownership, reaction, doubt, payoff, pain and reckoning. |
| D3 | Kestrel Strait / Ravellan are fictional prototype content. | Mechanically testable without importing real-faction constraints or expanding breadth. |
| D4 | Prototype starts at two normal interventions per cycle. | Creates scarcity without claiming final balance. |
| D5 | Lattice unlocks named Task Collection rather than a numeric bonus. | Capability must change action/information space. |
| D6 | V1 packet-processing loop is not a protected product invariant. | Human play falsified “polish the old loop” as the current path to fun. |
| D7 | Delegate executes the responsible officer's recommendation; other chiefs may visibly dissent. | Preserves command-by-exception without letting the player bypass scarcity by selecting a chief. |
| D8 | Standing direction is four plain-language questions applied red line → priority → style → tolerated cost. | Gives persistent strategic identity without a hidden score. |
| D9 | Kestrel is a six-cycle product laboratory, not the final campaign. | Test the core loop before breadth. |
| D10 | Intelligence uses bounded authored evidence + natural-language judgement; machine balance uses Pareto diagnostics; fun remains human-only. | Avoids confidence meters, scalar optimisation and synthetic fun claims. |
| D11 | HQ belief has one `ravellan-intent` claim with direction + picture state. | Enough uncertainty structure for Kestrel without generic intelligence architecture. |
| D12 | Recommendation uses legal/recommendation-applicable courses → command direction → commitment → authored chief tie. | Staff follows the commander before professional tie-breaking; no chief pre-filter/weighted score. |
| D13 | Persistent consequence state remains concrete Kestrel records. | Causal meaning/recovery over universal meters. |
| D14 | Lattice needs all three scheduled advances; missed build retains narrower one-token liaison fallback. | Sustained investment has qualitative payoff without mandatory build. |
| D15 | Final route depends on campaign-built preparation/warning/exposure/reserve/partner authority/commitments, not hidden opening posture. | Prevents secret-state rock-paper-scissors. |
| D16 | Command Room defaults locally to Delegate while the authoritative command set remains explicit. | Player acts on exceptions instead of approving routine work. |
| D17 | Headless lab includes Decision Elasticity and intelligence/coalition/deterrence/recovery strategy probes. | Detect fake choices and decorative strategies before human time. |
| D18 | Long-form Command Windows/Bets/chief memories/wider builds remain provisional post-gate hypotheses. | Preserve design direction without contaminating Kestrel. |
| D19 | Directed collection may inspect only target-authorised physical/action-history facts; hidden Ravellan posture alone can never change a sensor result. | Prevent disguised intent oracle. |
| D20 | C1 formal consultation is not Political's universal baseline; informal liaison wins a final tie unless standing partner direction selects commitment. | Binding promises should follow commander direction/personal intervention. |
| D21 | Cross-issue effects derive from the complete atomic command set and are order-independent. | Prevent issue/array order deciding campaign state. |
| D22 | C5 uses explicit `partner-authority = pending|none|joint|unilateral|concession`. | Relationship health and permission to act jointly are different things. |
| D23 | `request-partner-liaison` is the sole Kestrel `requiresIntervention` course. | Preserve the authored non-Lattice one-token fallback cost. |
| D24 | Quiet Denial is the restrained non-seizure fallback; final courses apply authoritative state effects before classification; successful Emergency always carries emergency-surge severe cost. | Prevent forced irrational escalation and prose-only final costs. |
| D25 | `usableWarning` is preparation-specific HQ assessment, not generic credible attribution. | Strong “they are coercing us” evidence is not seizure warning. |
| D26 | #107 + 3-player formative smoke precede the main browser UI tranche. | Falsify structure/loop cheaply before polish. |
| D27 | The untouched all-Delegate staff package must always be a legal complete command set. | Implicit delegation fails if staff's default intended orders are mutually incompatible. |
| D28 | An **active** C1 formal consultation channel provides rapid C5 consultation; ordinary C5 honour without that channel can still create C6 joint authority but is too slow for same-cycle sensitive action. | Restores the intended consultation-vs-tempo trade so `act-then-inform` is not dominated. |
| D29 | Kestrel attribution is one-shot: C5 use changes `credible → used` and removes C6 Hold And Expose. | “Use now vs preserve” must be a real timing decision rather than cumulative free benefits. |
| D30 | C2 `reroute-and-monitor` queues an indicator-only auxiliary-tasking clue that persists C3–C5. | Restores the original observation payoff so reroute is not simply quiet escort with greater civilian harm. |
| D31 | C5 visible Beacon reinforcement emits targeted discovery suspicion; quiet reinforcement does not. | Gives visible reinforcement a real deterrence path through #99's C6 strong-denial exception instead of making it a dominated political-risk version of quiet reinforcement. |
| D32 | C5 coalition→Ravellan observations are package-composed; one signal ID gets at most one non-contradictory value/effective point. | Legal simultaneous reinforcement/recovery must not create replay-invalid `credible` + `weak` coverage observations. |
| D33 | #107 includes **player-safe local course dominance** across hidden realities compatible with the same legitimate player information. | Elastic choices can still be objectively bad traps; legitimate hidden-state-dependent risk must remain allowed. |
| D34 | Exact coalition→Ravellan emissions are closed in [[37A-COALITION-TO-RAVELLAN-SIGNAL-MATRIX]]. | Opponent policy rows must be reachable from authored public behavior, not synthetic-only test observations or content improvisation. |
