# V2 Decision Log

Backlink: [[README]]

| ID | Decision | Why |
| --- | --- | --- |
| D1 | Make V2 a separately versioned ruleset. | Protect V1 save/replay truth and permit a genuine interaction-model experiment. |
| D2 | Use six command cycles and one bounded adversary. | Small enough for rapid human learning, large enough for intent, reaction, doubt, payoff, collision, and reckoning. |
| D3 | Use Kestrel Strait and Ravellan as fictional prototype content. | Freezes a mechanically testable slice without importing real factions or expanding scenario breadth. |
| D4 | Start at two intervention tokens per cycle. | Tests scarcity without implying final balance. |
| D5 | Lattice Cell unlocks task collection. | A capability must change information/action space, not add a numeric bonus. |
| D6 | #90 is superseded as a product premise, while its completed accessibility/legibility work remains reusable history. | Human play falsified “improve the existing loop” as the current path to fun. |
| D7 | Delegation executes the responsible officer's recommendation, with visible dissent. | Keeps command-by-exception meaningful without letting a player bypass intervention scarcity by selecting a chief. |
| D8 | Player intent is four Chief-of-Staff questions in ordinary language, applied red line → priority → default style → tolerable cost. | Preserves strategic identity without exposing implementation jargon or a score. |
| D9 | Use Kestrel Strait as the canonical six-cycle product laboratory. | Resolves the bounded adversary, pressure arc, Lattice, recovery and terminal test without pretending to be the final campaign. |
| D10 | Use evidence-backed natural-language intelligence judgement, Pareto laboratory diagnostics, and the approved 3/8-player human gates. | Avoids confidence meters, score optimization, and synthetic fun certification. |
| D11 | Kestrel HQ belief uses one `ravellan-intent` claim reduced from authored indicator/corroborating evidence into direction + picture-state, never probability. | Makes uncertainty implementable and replayable while preserving “I think X, but the picture is weak/conflicted.” |
| D12 | Staff recommendation applies legal/applicable courses → standing red line → priority → default style → tolerable cost → commitment → responsible-chief tie-break. Chief worldview advises/tie-breaks but cannot silently pre-filter command intent. | Preserves player ownership while keeping chiefs professionally distinct and explainable. |
| D13 | Use concrete Kestrel state records rather than a universal consequence meter. | Creates causal history/recovery without generic lifecycle architecture. |
| D14 | Lattice requires all three scheduled advances and then unlocks named Task Collection; non-Lattice liaison is narrower, costs an intervention and creates an obligation. | Gives sustained investment a qualitative payoff without making the capability mandatory. |
| D15 | Cycle 6 resolves from campaign-built preparation, exposure, warning, reserve, partner authority and commitments; final route does not match directly against hidden opening posture. | Prevents hidden-state rock-paper-scissors. |
| D16 | Command Room defaults every issue locally to Delegate while the submitted command set remains explicit. | Aligns interaction with the commander fantasy without weakening authority. |
| D17 | Headless design diagnostics include Decision Elasticity plus coalition-, intelligence-, deterrence- and recovery-first strategy probes. | Detects fake choices and decorative strategy families before human/UI time is spent. |
| D18 | Long-form Command Windows, Command Bets, chief memories and wider institutional builds remain provisional post-gate hypotheses only. | Plans toward a coherent full game without contaminating Kestrel. |
| D19 | Directed collection may inspect only the specific physical/action-history facts authored for its target; hidden Ravellan posture alone can never change a collection result. | Prevents a sensor from becoming a disguised intent oracle. |
| D20 | A binding C1 formal consultation agreement is not Political's unconditional default. Informal liaison wins a final tie unless standing partner direction selects the formal commitment. | A major promise should follow commander direction or personal intervention, not be silently universal. |
| D21 | Kestrel command-set composition is atomic across issues. C2 coordination and C5 partner authority are derived from the complete final-order set, never incidental agenda/array order. | Same-cycle consultation/escalation and simultaneous recovery/reinforcement otherwise produce contradictory or order-dependent state. |
| D22 | C5 has explicit `partner-authority` state (`pending/joint/unilateral/concession`); partner sentiment alone is not automatic joint military authority. | Separates relationship health from actual permission to act jointly. |
| D23 | `request-partner-liaison` is the sole Kestrel `requiresIntervention` alternative and can never be the delegated staff recommendation. | Preserves the authored non-Lattice fallback cost. |
| D24 | Quiet Denial is the restrained fallback for non-seizure terminal crises; final courses apply real reserve/partner state effects before classification, and Emergency Mobilisation always carries an emergency-surge severe cost when successful. | Prevents a Ravellan abort from forcing mobilisation and prevents terminal costs from existing only in prose. |
| D25 | `usableWarning` is preparation-specific HQ belief, not generic credible attribution. | Strong coercion evidence must not accidentally count as seizure warning. |
| D26 | Run #107 and the 3-player formative smoke immediately after #104, before the main browser UI tranche. | Structural/fun-loop failures are cheaper to discover in the complete headless slice than after UI implementation. |
