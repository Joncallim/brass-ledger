| D1 | Make V2 a separately versioned ruleset. | Protect V1 save/replay truth and permit a genuine interaction-model experiment. |

| D7 | Delegation executes the responsible officer's recommendation, with visible dissent. | Keeps command-by-exception meaningful without letting a player bypass intervention scarcity by selecting a chief. |
| D8 | Player intent is four Chief-of-Staff questions in ordinary language, applied red line → priority → default style → tolerable cost. | Preserves strategic identity without exposing implementation jargon or a score. |
| D9 | Use the supplied B2 Kestrel Strait design as the canonical six-cycle prototype. | It resolves adversary, branch, Lattice, recovery, terminal, and information ambiguity. |
| D10 | Use evidence-backed natural-language intelligence judgement, Pareto laboratory diagnostics, and the approved 3/8-player human gates. | Avoids confidence meters, score optimization, and synthetic fun certification. |
| D11 | Kestrel HQ belief uses one `ravellan-intent` claim reduced from authored indicator/corroborating evidence into direction + picture-state, never probability. | Makes uncertainty implementable and replayable while preserving the human “I think X, but our picture is weak/conflicted” experience. |
| D12 | Staff recommendation applies legal/applicable courses → standing red line → priority → default style → tolerable cost → commitment → responsible-chief tie-break. Chief worldview advises/tie-breaks but cannot silently pre-filter command intent. | Preserves player ownership while keeping chiefs professionally distinct and explainable. |
| D13 | Use concrete Kestrel state records for Beacon exposure/preparation, reserve, partner consent, explicit promises/obligations, Lattice investment and attribution. | Creates causal history/recovery without a universal meter or generic lifecycle framework. |
| D14 | Lattice requires all three scheduled advances and then unlocks one named Task Collection per Cycle 4/5; non-Lattice liaison is narrower, costs an intervention and creates an obligation. | Gives sustained investment a qualitative payoff without making the capability mandatory. |
| D15 | Cycle 6 resolves from campaign-built preparation, exposure, warning, reserve, partner authority and commitments; final route does not match directly against hidden opening posture. | Prevents the campaign from collapsing into hidden-state rock-paper-scissors and preserves multiple viable strategy histories. |
| D16 | Command Room interaction defaults every issue locally to Delegate, so the player acts mainly on exceptions; the authoritative command set still persists explicit dispositions. | Aligns interaction with the commander fantasy without weakening server/sim authority. |
| D17 | Headless design diagnostics include Decision Elasticity plus coalition-first, intelligence-first, deterrence-first and recovery-first strategy probes. | Detects fake choices and whether the promised strategic families are mechanically distinct before human time is spent. |
| D18 | Long-form Command Windows, Command Bets, chief memories and wider institutional builds remain provisional post-gate hypotheses only. | Plans toward a coherent full game without contaminating the bounded human-fun experiment. |
