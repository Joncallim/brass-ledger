# V2 Trade-off Register

Backlink: [[README]]

| ID | Options considered | Chosen option | Reason / downside | Reversible trigger |
| --- | --- | --- | --- | --- |
| T1 | Extend V1 loop / replace it in a V2 ruleset | Versioned V2 slice | Protects compatibility; temporarily duplicates contracts. | Human test shows the V1 loop is salvageable. |
| T2 | General adversary AI / four authored families | Authored bounded policy | Test fairness and counterplay cheaply; limited variety. | Slice shows policy is predictable for the wrong reason. |
| T3 | Universal meters / typed consequences | Concrete Kestrel exposure, promise, preparation, investment, partner and opportunity records | Preserves causal meaning; more schemas. | Two independent scenarios prove some lifecycles truly share semantics. |
| T4 | Full campaign / six cycles | Six cycles | Fast hypothesis test; cannot prove long-campaign retention. | Human evidence asks for a longer arc. |
| T5 | Finalise numbers / hold prototype values | Two interventions and authored discrete evidence states | Avoids false precision; balance remains provisional. | Laboratory plus human evidence supports stable values. |
| T6 | Bayesian/numeric intelligence / authored bounded evidence | One Kestrel claim with indicator/corroborating evidence and natural-language judgement | Easier to reason/replay and less gamey; may feel coarse. | Human players cannot distinguish meaningful uncertainty or collection value. |
| T7 | Weighted staff utility / lexicographic command direction | Red line → priority → style → tolerated cost, then commitment/chief tie-break | Makes delegation visibly belong to the commander; can produce intentionally non-optimal professional choices. | Human players perceive staff as nonsensical rather than faithfully following intent. |
| T8 | Click Delegate on every issue / implicit local delegation | Issues begin delegated; player interacts mainly with exceptions | Removes approval-workflow boredom; risk that players miss what staff will do. | Human tests show players cannot tell what was delegated or feel insufficient ownership. |
| T9 | Final hidden-posture counter / history-based terminal matrix | Route availability/outcome depends on preparation, warning, reserve, partner authority and commitments | Rewards the campaign built instead of secret-state guessing; more authored predicates. | Headless/human tests show final choice is opaque or routes remain effectively identical. |
| T10 | Only policy-outcome testing / counterfactual Decision Elasticity | Branch identical pre-states across legal alternatives and flag fake choices | Catches choices that only change prose; adds laboratory execution cost. | Diagnostics are too expensive/noisy to identify actionable inelastic decisions. |
| T11 | Freeze long-form architecture now / keep post-gate hypotheses provisional | Record Command Windows, Command Bets, chief memories and wider builds in a non-authoritative post-gate note | Preserves direction without contaminating Kestrel. | Human gate passes and a post-gate phase is authorised. |
| T12 | Let collection result tables read hidden opponent posture / restrict each target to observable physical/action-history facts | Posture-blind target-specific observation rules | Prevents sensors becoming an intent oracle; some legitimate evidence can now mislead when the opponent is testing/changing. | Human/lab evidence shows the target cannot communicate a useful distinction without an additional explicitly observable world fact. |
| T13 | Apply issue effects sequentially / compose the complete atomic command set | Derive C2/C5 cross-issue effects from the full final-order set; aggregate ordinal deltas order-independently | Prevents array/agenda order from deciding partner authority or recovery outcomes; requires explicit coordination rules. | A future scenario proves every issue is truly independent. |
| T14 | Treat healthy partner sentiment as automatic operational permission / explicit partner-authority state | Add `pending/joint/unilateral/concession` authority result at C5 | Makes consultation mechanically meaningful and separates relationship from permission; adds one concrete record. | Human play shows the distinction is too hard to understand despite clear presentation. |
| T15 | Terminal costs only in prose/classification / terminal actions mutate authoritative state | Joint/Emergency/Expose alter reserve/partner/attribution before final vector/classification | Makes final choices mechanically elastic; more terminal transition tests. | Laboratory proves the extra state changes add no meaningful route separation. |
| T16 | Formal consultation as Political's universal baseline / informal liaison baseline unless command direction selects commitment | Binding promise follows command philosophy or personal override | Preserves meaningful C1 commitment choice; partner-first intent still delegates it. | Human play shows players never understand why the commitment matters. |
| T17 | Allow any legal alternate to become staff recommendation / explicit commander-only course | `request-partner-liaison` alone has `requiresIntervention` | Preserves the promised one-token fallback cost; adds one bounded authority flag. | Later design removes intervention cost from liaison or introduces a reusable command-authority taxonomy. |
| T18 | Build UI before structural/human smoke / test complete headless game first | #107 + 3-player formative smoke precede #105/#106 | Avoids polishing a loop already falsified by structure or fresh-player evidence; delays UI start. | Headless interaction is shown to be too unlike the browser to provide useful formative evidence. |
