# Commander-only courses

Exactly:

- C2 public-accusation;
- C4 request-partner-liaison;
- C5 use-attribution

are `requiresIntervention = true`.

They remain player-legal when prerequisites hold, never enter staff recommendation candidates and always consume one normal intervention.

# Global validation

Every reachable issue state must have:

- stable unique issue/order IDs;
- one responsible officer;
- explicit player-known prerequisites;
- metadata backed by real mechanics;
- an authored final tie where needed;
- no hidden-truth tags/ties;
- a legal composed all-Delegate package.

### Professional tie from HQ intelligence

Apply only after standing-direction/commitment/package filters.

1. warning usable → quiet reinforce > visible reinforce > hold;
2. else assessment preparation → quiet > visible > hold;

## `c5-attribution` — Political

Exists only while persisted #101 attribution opportunity is:

```text
{ state: credible, direction: preparation | coercion }
```

The issue's player-safe title/copy must identify the claim direction without exposing internal enums, e.g.:

- “We can substantiate a seizure-preparation case.”
- “We can substantiate a coercive pressure case.”

A generic subjectless “credible case available” issue is invalid.

### `hold-attribution`

- quiet;
- staff baseline and **always staff recommendation** because Use is commander-only;
- preserves `{ credible, same direction }` for C6;
- preserves protected source;
- gives up immediate public/discovery effect.

### `use-attribution`

- requiresIntervention true;
- supports partner when politically usable;
- never supports understanding;
- partner-sensitive;
- partner style when coordinated else visible;
- political friction if unilateral;
- severe attribution-source-exposed;
- persists `{ credible, direction } → { used, same direction }`;
- removes C6 Hold And Expose;
- safe known-cost/reason copy identifies which claim is being made.

#100 internal public-case basis never directly creates this issue. Only #101 persisted opportunity does.

The staff recommendation remains Hold for **both** claim directions. Direction affects player-legitimate copy, causal history and later terminal legality—not a hidden staff preference score.

# Rejection conditions

Reject metadata if support lacks real mechanic, a beneficial political action becomes a universal free baseline, a commander-only course can Delegate, warning is ignored/inferred from assessment, visible style auto-accuses, partner intent auto-burns source, the C5 attribution issue loses the claim direction, a coercion case is described as preparation evidence, #100 basis bypasses #101 state, dead signal metadata returns, a tie uses array/randomness, ceremonial work is added or advice reads hidden Ravellan truth.
